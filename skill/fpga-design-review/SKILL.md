# FPGA 设计证据核查工作流

**状态：流程草案，尚未完成独立 Skill 加载和执行验收。**

## 目标

辅助审查 FPGA 网络测量系统的数据路径、HLS 任务组织、软硬件接口、时序及验证证据。此工作流是技术核查参考，不自动修改工程，也不代表完成仿真、综合或板级验证。

## 输入

- RTL/HLS/PS 源码与模块接口定义
- Block Design、XDC、IP 配置及工程脚本
- HLS C 仿真、综合、实现、时序、CDC 和板级测试记录
- 对应工具版本、工程版本和数据集条件

## 核查步骤

1. **确认版本基线：** 记录源码与配置的版本身份，区分历史参考结果和本轮真实执行结果。
2. **检查接收数据路径：** 核对 PHY/RGMII、MAC、AXI Stream、协议解析及五元组输出的接口与有效信号。
3. **检查 HLS 任务依赖：** 比对流水阶段、FIFO、状态访问顺序与背压处理，核实 UPDATE、QUERY、RESET 的行为。
4. **检查控制与查询：** 核对 PS/PL 寄存器、DMA 传输方向、数据位宽与查询结果。
5. **检查工程时钟与约束：** 结合 XDC、时钟树和 CDC 报告判断风险，不能只依据名称认定跨域同步已完成。
6. **检查性能口径：** 分开报告局部 II、任务完成间隔、网络入口 PPS、吞吐率与统计误差，确保每个数字能追溯到其测试条件。
7. **核对验证证据：** 按仿真、综合、实现、软件构建和上板运行逐项记录真实结果与日志，不把人工推断写作通过项。

## 输出

- 模块与信号数据流说明
- 设计选择、效果及代价的技术核查表
- 性能指标和测试条件对应表
- 版本身份、工程状态及未闭合问题摘要

## 验收边界

任何成功状态都必须有对应工具日志、测试记录或实板证据。此 Skill 本身尚未通过独立运行验收，使用者需人工复核每项结论。
