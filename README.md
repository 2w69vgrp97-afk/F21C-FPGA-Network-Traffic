# F21C FPGA Network Flow Measurement

This private repository is a documentation-only placeholder for the F21C Candidate-B FPGA network-flow measurement prototype. **Source code is not yet included** while ownership, third-party rights and confidentiality are confirmed. This repository is not a complete competition source delivery.

The prototype targets Zynq-7020 on the AC7021B platform and uses a Funnel-Sketch-based design with PS/PL cooperation. The archived project requires AMD Vivado, Vitis and Vitis HLS 2025.2, device support, platform/BSP and appropriately licensed IP, including AXI Ethernet. Hardware configuration, generated drivers, build scripts and design sources are not provided here.

Historical delivery records report limited project-opening, HLS C simulation and PS build checks. A complete source-to-final-BIT rebuild and exact original ELF reproduction remain unverified. The Candidate-B board-test version identity is unknown and CDC risks remain open. The latest recorded B bitstream is TEST_ONLY. This placeholder cannot be used to reproduce the system.

Source files may be added only after the appropriate rights holders approve private sharing and the files are reviewed for sensitive information. Competition submission requirements and reviewer access remain to be confirmed.
